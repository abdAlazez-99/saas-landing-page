# Whitespace - SaaS Landing Page

A modern and professional SaaS landing page built from a Figma design, tailored for project management and team collaboration software.

## 🔗 Project Links
* **Original Figma Design:** [Whitespace SaaS Landing Page](https://www.figma.com/design/t5qzlbipfTTHgNkJvlSMz5/Whitepace---SaaS-Landing-Page--Community-?node-id=1-21628&p=f&t=EifuS2U7YfyHgvsT-0)

---

## 🛠️ Tech Stack
* **HTML5:** For structuring semantic elements and building the page layout.
* **CSS3:** Utilizing CSS Variables for easy maintenance of colors and spacing, along with a fully responsive layout.
* **Font Awesome (v7.3.1):** For integrating icons across navigation and components.
* **Google Fonts (Inter):** The primary font family used to ensure a clean and modern user interface.

---

## ✨ Features
* **Fully Responsive Design:** Adapts smoothly across various screen sizes (mobile devices, tablets, and desktops).
* **Flexbox Layout:** Clean and precise alignment of content and sections.
* **Smooth Transitions:** Subtle hover effects and transitions for buttons and interactive elements.
* **Clean File Architecture:** Organized modular structure separating general components and specific styling.
